## 实现与源码

Ascend C 内核以原始 16 位数据复制 FP16/BF16，保留 NaN、Inf 和负零位模式。Q、K、V 每次独立分配；输入保持不变；L=0 不读取历史缓存。支持非对齐 D 和带 storage offset 的连续视图，使用当前设备及 stream，输入通过分配器 recordStream 管理异步生命周期。

历史数据按 32 Ki 元素分块，交错处理 K/V。大输入使用三个 64 KiB UB 缓冲区及最多 48 个 Vector 核，其他输入使用两个缓冲区及最多 40 核。对齐输入批量追加 H×D 数据，非对齐输入逐行处理。

大输入第一次普通调用采用输入正常缓存、输出绕过 L2；随后同输入存储与 stream 的调用采用输入绕过 L2、输出正常缓存。每次调用完整计算输出，仅启动一次内核；没有额外预热、在线试跑、数据缓存或输出复用。每线程只保留有界的元数据及弱 Storage 引用，输入更新、切换 stream、提前释放及地址变化已有补充测试。

Python C++ 绑定复用六个主机 ACLTensor 描述符；形状、步长、dtype、storage offset 变化时重建，存储基址变化时在第一阶段前使用 aclSetRawTensorAddr 更新。每次仍执行两阶段 ACLNN 调用，不缓存 executor。主机描述符不持有 NPU 张量存储。Python 属性契约保持 headNum/headDim，原生 ACLNN 内部增加 cacheMode 参数用于缓存策略。
